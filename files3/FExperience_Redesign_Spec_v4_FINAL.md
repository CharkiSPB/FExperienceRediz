## 0. Суть решения

Фон светлый, оранжевый — фирменный цвет (не декоративный акцент), стекло — точечное, Apple-style. Ориентиры: Financial Times, Monocle, Kinfolk, Apple Editorial, Forbes print. Не Bloomberg-терминал, не tech-startup bento (Linear/Vercel), не туристический luxury travel.

Один принцип держит всю систему вместе: **1–2 по-настоящему проработанных "wow"-момента на странице, всё остальное — тихое.** Не равномерно наляпанное стекло и градиенты везде, а осознанная редкость: одна featured-карточка, один hero-приём, одна карта.

## 1. Продуктовое позиционирование

FExperience — деловая платформа Forbes, дающая предпринимателям доступ к людям, рынкам и возможностям через кураторские бизнес-экспедиции. Не туристический продукт, не luxury travel — визуально и текстово это продолжение делового медиа Forbes.

На сайте уже есть точный манифест (`/about`), переносим почти дословно:

> «Мы помогаем предпринимателям открывать новые горизонты на самых перспективных рынках — в России и за рубежом. Мы не организуем туристические поездки. Мы проводим бизнес-экспедиции. Результат — ваше взвешенное стратегическое решение об экспансии бизнеса.»

**Модель опыта:**
```
Market → Insight → Expert Access → Expedition → Decision
```

Поправка: сайт сегодня успешно продаёт через конкретные горящие экспедиции (даты, счётчик мест) — отказываться от этого не нужно. Платформенное позиционирование — в заголовке и структуре hero; конкретная ближайшая экспедиция — вспомогательный слой под ним, не единственный смысл первого экрана.

## 3. Brand Experience Principles

- **Discover Before Others** — эмоция "я получаю доступ к рынку раньше других", не "я покупаю поездку".
- **Premium without Luxury** — премиальность через пространство, типографику, ритм и контент, не золото/мрамор/статусность.
- **Information over Decoration** — при выборе "эффектнее или понятнее" — всегда понятнее.
- **Calm Motion** — пользователь не должен замечать анимацию, должен замечать качество.
- **Photography** — только инфраструктура, деловая среда, предприниматели, индустрия. Никаких пляжей, отелей, самолётов, достопримечательностей. Фото на `/about` (деловая программа, 4 кадра) — эталон подбора на будущее.
- Ориентиры визуального языка: Financial Times, Monocle, Kinfolk, Apple Editorial, Forbes print — не Bloomberg-терминал и не Apple/Linear/Vercel tech-bento. Карточки должны читаться как **страницы делового досье**, не как SaaS-лендинг.

## 4. Дизайн-система

### 4.1 Цвет

```css
--bg-canvas: #FAFAF8;
--bg-surface: #F5F2EC;
--bg-elevated: #FFFFFF;

--text-primary: #1A1A1A;
--text-secondary: #6D6D6D;
--text-tertiary: #A0A0A0;

--orange-700: #B7410E;   /* текст/ссылки/цифры на светлом — лучший контраст */
--orange-600: #FF6B2C;   /* базовый бренд-оранжевый — CTA, теги, активная навигация */
--orange-500: #FF7722;   /* вторичный акцент */
--orange-400: #FF8A54;   /* градиенты, hover */
--orange-300: #FFB089;
--orange-200: #FFE8D6;   /* фон тегов/плашек */
--orange-100: #FFF0E8;   /* самый светлый — фон секций-акцентов */

--gradient-signature: linear-gradient(45deg, #B7410E 0%, #FF7722 55%, #FFE8D6 100%);
--continent-outline: #FFE6D8;
```

**Правило дистрибуции:** оранжевый — 25–35% визуального языка, часть бренда, не редкий акцент. Используется в CTA, активной навигации, тегах, крупных цифрах статистики, pull quotes, маршрутных линиях, разделителях. Запрещено заливать оранжевым фон полноэкранных секций — только акценты, плашки, обводки, текст.

### 4.2 Типографика

```
Заголовки (serif):  Playfair Display
Текст (sans):        HelveticaNeueCyr (Light/Regular)
```

Крупные цифры статистики (">60%", "50+" — уже на сайте) — Playfair Display, `--orange-600`. Сильный приём, сохранить и унифицировать по всему сайту.

### 4.3 Стекло — три уровня

**Level 01 — базовое** (карточки, панели):
```css
background: rgba(255,255,255,.55);
backdrop-filter: blur(20px);
border: 1px solid rgba(255,255,255,.85);
box-shadow: 0 8px 40px rgba(0,0,0,.06);
```

**Level 02 — приподнятое** (hover, активные карточки):
```css
background: rgba(255,255,255,.72);
backdrop-filter: blur(24px);
```

**Glass Signature — редкий, третий уровень** (референс: карточка "Launch Your Ambitions" со светящимся контуром по углам):
```css
background: rgba(255, 250, 244, .6);
backdrop-filter: blur(18px);
--glow-color: rgba(255,107,44,.35);
box-shadow: 0 0 24px var(--glow-color), 0 12px 48px rgba(0,0,0,.08);
/* контур — короткие SVG-дуги 2–3px в --orange-500 по 2 углам, не сплошная рамка */
```
Только для: featured-карточки медиа-раздела, обложка featured-статьи в Insights, hero-плашка ближайшей экспедиции. Не больше 1 карточки на экран.

**Liquid Glass — самый редкий элемент** (капля янтаря, а не UI-компонент):
```css
background: linear-gradient(135deg, #FF8A54, #FF6B2C);
box-shadow: 0 0 40px rgba(255,107,44,.25);
transform: scale(1.03); /* hover */
```
Только для: `Стать участником` / `Подать заявку` / `Подписаться на рассылку`. Вторичные кнопки ("Подробнее") — плоская контурная пилюля. Как только это становится общим паттерном — эффект теряется.

Референсы стекла: Apple Vision OS, Arc Browser, Linear, Raycast — только механика стекла, не общая эстетика.

### 4.4 Карточки и Bento

Bento остаётся, но как **"editorial dossier grid"**: карточки — страницы делового досье, не модули дашборда. Меньше строгой равномерной сетки, больше асимметрии, крупные serif-заголовки внутри карточек, тонкие оранжевые линии-разделители.

```
Card radius: 24px (featured), 16px (обычные)
Card padding: 32–40px
Hover: translateY(-6px), тень усиливается
Featured card: фон --gradient-signature — единственное цветное "пятно" в светлой сетке
```

### 4.5 Карта — компонент "Свой континент"

Заменяет единый `world-map.svg`, который сейчас одинаково стоит на всех страницах. Новый компонент **привязан к конкретной экспедиции**: на вход — код региона + координата активной точки, на выходе — свой контур для каждой страницы.

```
Контур континента — 1.5px, --continent-outline, увеличен так, чтобы активная страна была в визуальном центре
Соседние точки (другие страны того же континента, без ссылок, для масштаба) — контурный круг 6px, --text-tertiary, opacity .5
Активная точка — залитый круг 12px, --orange-600, подписана, pulse (opacity 0.4→0, 2s loop) — кроме статуса "Завершена" (см. 6.4)
Плашка-подпись — Glass Level 01, заголовок Playfair 20–24px
```

```
/expeditions/south-africa → контур Африки, точка на ЮАР
/expeditions/vietnam      → контур Азии, точка на Вьетнаме
/expeditions/india        → контур Азии, точка на Индии
/expeditions/brazil       → контур LATAM, точка на Бразилии
/expeditions/kenya        → контур Африки, точка на Кении
/expeditions/morocco      → контур Африки, точка на Марокко (без pulse)
/expeditions/sakhalin     → контур России/Дальнего Востока (вне 4 цветов регионов)
/expeditions/thailand,
/expeditions/indonesia    → контур Азии, соответствующая точка
```

На директории (`/expeditions`) общей карты-обзора больше нет — эту роль выполняет Continental Navigation. Своя карта появляется только на детальной странице конкретной экспедиции.

### 4.6 Motion

Спокойные короткие анимации (300–500ms, ease-out). Карта "дорисовывается" при скролле, карточки программы дня всплывают — разрешено, поддерживает сторителлинг.

Заголовок hero — разовая анимация появления при загрузке (fade/slide). **Живая подмена текста в зависимости от времени суток исключена из ТЗ** — противоречит Calm Motion и Information over Decoration, риск восприниматься как гаджет ради гаджета для аудитории, решающей вопрос выхода на рынок за $50k+. Может остаться опциональным A/B-экспериментом, не обязательной фичей релиза.

## 6. Постранично

Общий шаблон: `Header → Page Hero → Content Sections → CTA Layer → Footer`.

### 6.1 Homepage

**Header** — светлый, липкий, Glass Level 01 при скролле.

**Hero — сплит-стекло.** Единый fullbleed видеофон (деловая среда, не туризм), поверх него — крупный блок frosted glass, сквозь который частично проступает decorative wordmark (15–20% непрозрачности), поверх стекла — читаемый заголовок платформенного уровня и CTA полной контрастности. Не "текст слева / фото справа" — приём почти у всех травел-сайтов, а текст, прорастающий сквозь стекло.

Под hero — тонкая плашка (не блюр, светлая пилюля с рамкой) с ближайшей активной экспедицией: ротируется между ЮАР (15–21 ноября 2026), Вьетнам (14–20 марта 2027), Индия (сентябрь 2026) — по ближайшему дедлайну/меньшему числу мест.

**Market Reality (bento-статистика)** — три текущие цифры сайта (">60% неудачных экспансий", "50+ лояльных контактов", ">40% стартапов из-за невостребованности продукта") — светлые bento-карточки, крупная serif-цифра `--orange-600`.

**Platform Statement** — блок "FExperience — специальный проект команды Forbes..." переносится почти дословно.

**Continental Navigation** — 4 карточки регионов.

**Featured Markets (bento)** — сетка направлений, не первый экран, а раздел ниже Continental Navigation. Featured-карточка — `--gradient-signature`, с Liquid Glass CTA. Остальные — светлые.

**How FExperience Works** — блок "Почему FExperience" (уникальный нетворкинг Forbes / медийное сопровождение / экспансия без купюр / контакты с госструктурами / оценка бизнес-модели / культурное погружение) — переносится, нумерованные карточки с тонкими оранжевыми разделителями.

**Media Layer** — цифры присутствия Forbes (журнал >1М охват, сайт >10М читателей/мес, видео >100 тыс.) — усилить визуально, это единственное, что явно транслирует "это Forbes, а не турагентство".

**Testimonials** — карусель светлых Glass-карточек (Гайдарович, Апалькова, Адамович, Цыганов, Демченко, Николаев), фото в мягких круглых рамках.

**FAQ** — аккордеон, вопросы с сайта ("Сколько дней длится поездка?", "Какой уровень английского нужен?", "Сколько стоит участие?", "В чём уникальность экспедиции?").

**Final CTA** — Liquid Glass, светлая секция с тёплым radial-градиентом (не заливка оранжевым).

**Footer** — см. 6.7.

### 6.2 О нас

Реальная структура страницы, задача редизайна — чисто визуальная, контент не меняется:

1. **Манифест** — крупный serif по центру, тонкая оранжевая линия под "МЫ ПРОВОДИМ БИЗНЕС-ЭКСПЕДИЦИИ".
2. **"Деловая программа и погружение в локальную культуру"** — текст + 4 фото в асимметричном bento (одно крупное + три поменьше), светлые рамки.
3. **Due Diligence** — 9 карточек (безопасность в стране, деловой климат, регуляторная среда, логистика, реальный запрос бизнеса, культурные барьеры, финансовая инфраструктура, цифровизация экономики, стоимость выхода на рынок) — карточки-досье, тонкая линия-иконка `--orange-600`, порядковый номер как в юридическом документе (01/09 … 09/09).
4. **Команда проекта** — 3 карточки (Марина Матыцина, Денис Кошкин, Анастасия Никитина), бейдж Forbes Russia, фон Glass Level 01 вместо текущей тёмной подложки.

### 6.3 Экспедиции — Directory

Статусы:
```
Активна   — ЮАР (15–21 ноября 2026), Вьетнам (14–20 марта 2027), Индия (сентябрь 2026, Нью-Дели)
Скоро     — Бразилия, Сахалин, Таиланд, Индонезия, Кения
Завершена — Марокко (10 спикеров)
```

Статус — бейдж-пилюля вверху карточки, не текстовая подпись: `Активна` — заливка `--orange-100`, текст `--orange-600`; `Скоро` — контурная пилюля `--text-tertiary`; `Завершена` — приглушённая, `--bg-surface`, `--text-secondary`, карточка визуально "тише" (без hover-подъёма). Считывается за долю секунды без чтения текста.

Структура страницы: Hero → Continental Navigation (точка входа, не сразу сетка) → Featured Markets → Industry Explorer (фильтр по отрасли) → сетка карточек со статус-бейджами → Upcoming Markets.

### 6.4 Детальная страница экспедиции — три шаблона по статусу

Шаблон зависит от статуса карточки, не от произвольного "состояния". У экспедиций "Скоро" нет ни программы, ни экспертов — это ожидаемая структура, не пробел в контенте.

**Шаблон 1 — Активна (ЮАР, Вьетнам, Индия). Полная программа.**
- Hero: даты, заголовок "Бизнес-экспедиция в [страна] с Forbes", 3 стеклянные пилюли-тега (погружение в культуру / эксклюзивный нетворкинг / лучшие бизнес-практики).
- Карта "свой континент" сразу под hero.
- "Что включено" — 6 карточек с фоновым фото (медийное сопровождение, бизнес-сессии/нетворкинг, культурные мероприятия, отель 5*, VIP-трансферы, питание).
- "Программа экспедиции" — по ЮАР реально 6 дней с named-локациями (Lanzerac Wine Estate, бизнес-сессия "Африка в фокусе", Стелленбосский университет, локальное предприятие + Кейптаун, Babylonstoren + "Говорят местные", мыс Доброй Надежды). Вертикальный таймлайн, номер дня на `--gradient-signature`, карточка всплывает при скролле.
- "Наши эксперты" — по ЮАР 12 карточек: 9 внешних экспертов + 3 представителя Forbes Russia. Сетка 4×3, позиция видна сразу под фото, не по hover (для деловой аудитории — функциональность, не игра в интерактивность).
- Форма заявки — выпадающий список с выбором экспедиции (Индия / ЮАР / Вьетнам) + имя, телефон, email, согласие.

**Шаблон 2 — Скоро (Бразилия, Сахалин, Таиланд, Индонезия, Кения). Компактный.**
Без секций "Программа" и "Наши эксперты" — их отсутствие в разметке, не пустые заглушки.
- Hero с теми же тремя тегами + короткий питч под рынок (у Бразилии — "Латинская Америка: агросектор, энергетика, финансы").
- Карта "свой континент" — единственный визуальный контент страницы, кроме hero.
- Текст-приглашение + lead-форма: «Вам интересна локация? Оставьте заявку — и эта точка может стать следующей на карте FExperience» (реальный текст с сайта, сохраняется).
- "Похожие экспедиции" — 2–3 карточки активных направлений того же региона.

**Шаблон 3 — Завершена (Марокко). Recap.** *(предложение, требует вашего подтверждения перед реализацией — раньше такого шаблона на сайте не было)*
Логика — "витрина результата", конвертирует в подписку, а не в заявку на прошедшую поездку.
- Hero без счётчика мест и дат заезда — "Экспедиция состоялась" + агрегированная цифра ("10 спикеров").
- Карта "свой континент", точка на Марокко, без pulse-анимации.
- Отзывы участников именно этой экспедиции (Апалькова, Адамович, Цыганов — уже помечены "Марокко 2025" в карусели на главной), закреплены на странице постоянно.
- Ссылки на статьи по направлению (9 из 13 статей на `/articles` — про Марокко/Африку).
- CTA — "Подписаться на анонсы" или "Смотреть активные экспедиции", не "Стать участником".

Если шаблон 3 избыточен для первого этапа — Марокко может временно использовать упрощённую версию шаблона 2 (без lead-формы, с отзывами вместо приглашения).

### 6.5 Статьи / Insights Hub

Позиционирование: Premium Editorial Magazine, не база знаний. Реальная таксономия: категории **марокко, африка, прочее** (13 статей).
