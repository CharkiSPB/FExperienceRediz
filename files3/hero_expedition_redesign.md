# HERO — переработка детальной страницы бизнес-экспедиции

## Задача

Переработать **только Hero-блок детальной страницы экспедиции**.

Сохранить текущую сильную основу: кинематографическую фотографию, крупную editorial-типографику, тёмный premium-настроенный Hero, оранжевый фирменный акцент, навигацию, дату, описание и CTA.

Главное изменение — полностью исправить концепцию карты справа.

### Критически важно

Текущая реализация воспринимается как:

> **прямоугольная стеклянная карточка → внутри неё контур Африки.**

Это не целевая концепция.

Нужно:

> **сам контур континента является стеклянным объектом.**

Прямоугольную glass-card вокруг карты необходимо полностью убрать.

---

# 1. Hero — 100vh

Hero должен быть полноценным первым экраном:

- `min-height: 100vh`;
- на desktop по возможности `height: 100vh`;
- содержимое вертикально центрировано;
- фотография занимает весь экран;
- карта справа является крупным самостоятельным визуальным объектом;
- Hero не должен ощущаться как просто широкая картинка фиксированной высоты.

Целевая композиция:

```text
┌───────────────────────────────────────────────────────────────┐
│                         NAVIGATION                            │
│                                                               │
│   БИЗНЕС-ЭКСПЕДИЦИЯ                    стеклянный контур      │
│                                                               │
│   ЮАР                                    ╭──────────╮         │
│                                          │   •      │         │
│   15–21 НОЯБРЯ 2026                      │     •    │         │
│                                          │       •  │         │
│   описание                               ╰──────────╯         │
│                                                               │
│   [ Стать участником ]                                        │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

Правая форма в реальности должна быть **силуэтом Африки**, а не прямоугольником.

---

# 2. Что оставить

Не переделывать без необходимости:

- полноэкранную кинематографическую фотографию;
- затемнение фотографии;
- левую текстовую композицию;
- навигацию;
- фирменный оранжевый цвет;
- дату;
- описание;
- CTA;
- общую premium/editorial/corporate атмосферу;
- горизонтальную композицию Hero.

Hero должен продолжать ощущаться как **главный экран бизнес-экспедиции**, а не туристического сайта.

---

# 3. Сам континент = стекло

## Главный принцип

Не делать:

```text
[ стеклянная карточка ]
        Африка
```

Делать:

```text
        ╭─────╮
       /       \\
      │ Африка │   ← сама форма Африки является стеклом
       \\       /
        ╰─────╯
```

Сам силуэт Африки должен выглядеть как большой полупрозрачный glass-layer, наложенный непосредственно на фотографию.

---

# 4. Полностью убрать прямоугольную glass-card

Удалить визуально:

- прямоугольный контейнер вокруг карты;
- `border-radius` вокруг карты;
- большой прямоугольный border;
- прямоугольный glassmorphism;
- card background;
- отдельный прямоугольный footer карты.

Если технический wrapper нужен для layout, он должен быть визуально невидимым:

```css
background: transparent;
border: none;
box-shadow: none;
```

**Единственным визуальным объектом должна быть форма континента.**

---

# 5. Как должен выглядеть стеклянный континент

Силуэт:

- крупный;
- полупрозрачный;
- лёгкий;
- премиальный;
- немного светлее/холоднее фотографии;
- без тяжёлой серой заливки.

Можно использовать сочетание:

- `opacity`;
- `backdrop-filter`;
- тонкого светлого outline;
- мягкой внутренней засветки;
- очень мягкой тени;
- SVG mask / clip-path.

Пример направления:

```css
background: rgba(255, 255, 255, 0.06);
border: 1px solid rgba(255, 255, 255, 0.28);
backdrop-filter: blur(8px);
box-shadow:
  inset 0 0 30px rgba(255,255,255,0.05),
  0 12px 40px rgba(0,0,0,0.08);
```

Значения адаптировать под реальный фон.

Целевое ощущение:

> **прозрачная стеклянная форма континента находится прямо перед фотографией.**

Не делать непрозрачную серую карту.

---

# 6. Контур должен читаться

В текущем варианте карта слишком теряется.

Нужен баланс:

- не настолько слабый, чтобы её нельзя было заметить;
- не настолько яркий, чтобы она стала обычной белой картой.

Контур должен читаться с первого взгляда как:

> **дорогой прозрачный объект / стеклянная карта / навигационный слой.**

Особенно хорошо он должен быть заметен на более тёмных участках фотографии.

---

# 7. Размер и положение

Сделать континент значительно крупнее текущей карты.

Ориентир:

- примерно `35–45vw` по ширине;
- естественные пропорции Африки;
- правая часть Hero;
- можно слегка вывести силуэт за правую границу viewport на 5–10%;
- не зажимать его по вертикали;
- не центрировать внутри невидимой «карточки».

Континент должен ощущаться частью фотографии.

Он становится **вторым главным визуальным объектом Hero**.

---

# 8. Точки маршрута

Для текущего примера ЮАР использовать:

- Кейптаун;
- Стелленбос;
- мыс Доброй Надежды.

Точки:

- маленькие;
- оранжевые;
- аккуратные;
- с очень мягким glow;
- без туристических pin-иконок.

Предпочтительно:

```text
маленькая точка + мягкий glow
```

а не классический map-pin.

---

# 9. Маршрут

Маршрут между точками должен находиться непосредственно на стеклянном континенте.

Использовать:

- тонкую оранжевую линию;
- аккуратную геометрию;
- минимум декоративности;
- небольшой glow.

Маршрут должен ощущаться как **деловая экспедиционная навигация**, а не туристический GPS.

Не использовать:

- самолётики;
- массивные стрелки;
- туристические pin-иконки;
- компасы;
- декоративные глобусы;
- пунктир в стиле туристического приложения.

---

# 10. Подписи точек

Можно использовать небольшие тёмные полупрозрачные pills:

```text
● Стелленбос
● Кейптаун
● Мыс Доброй Надежды
```

Pills:

- небольшие;
- тёмные;
- полупрозрачные;
- с лёгким blur;
- светлый текст;
- без массивной рамки;
- без яркого свечения.

Они должны быть вторичным уровнем интерфейса, а не набором карточек.

---

# 11. Убрать отдельный footer карты

Не использовать отдельный блок вида:

```text
АФРИКА
ЮАР · Кейптаун
```

внутри прямоугольной карточки.

Информация уже считывается через:

- название экспедиции;
- континент;
- точки;
- маршрут.

Если дополнительная подпись нужна, сделать её очень лёгкой и непосредственно частью картографического слоя.

---

# 12. Левая часть

Сохранить текущую структуру:

### Eyebrow

`БИЗНЕС-ЭКСПЕДИЦИЯ`

Оранжевый, небольшой uppercase.

### Заголовок

`ЮАР`

Крупная editorial serif-типографика.

### Дата

`15–21 НОЯБРЯ 2026`

### Описание

Сохранить текущий деловой смысл:

> ЮАР — крупнейшая экономика континента и точка входа в Африку: энергетика, агропром и банковский сектор Западного Кейпа.

### CTA

`Стать участником`

Фирменная оранжевая кнопка.

Заголовок «ЮАР» остаётся главным текстовым якорем.

---

# 13. Фотография

Фотография продолжает быть основой всей композиции.

Не затемнять её до однотонного фона.

Логика слоёв:

```text
фотография
↓
cinematic dark overlay
↓
стеклянный континент
↓
маршрут + точки
↓
текст
```

Не использовать отдельный прямоугольный фон под картой.

---

# 14. Визуальное сообщение

Hero должен одновременно сообщать:

### Это бизнес
Через строгую типографику, композицию и отсутствие туристического UI.

### Это экспедиция
Через маршрут, точки и карту.

### Это конкретный рынок
Через фотографию, страну и локальные точки.

### Это premium-продукт
Через минимализм, пространство, стеклянный объект и сдержанную анимацию.

---

# 15. Анимация

Если в проекте уже есть animation framework:

1. фотография появляется плавно;
2. текст появляется мягко;
3. стеклянный контур проявляется постепенно;
4. маршрут прорисовывается;
5. точки появляются последовательно.

Ориентир:

```text
0.0s — Hero image
0.2s — eyebrow
0.3s — title
0.4s — description
0.5s — glass continent
0.8s — route
1.0s — markers
```

Анимация должна быть медленной и premium.

Не использовать bounce, flashy motion или резкие масштабирования.

---

# 16. Responsive

## Desktop

Основная композиция:

```text
[ текст ]                         [ стеклянная Африка ]
```

## Tablet

Уменьшить континент, но сохранить его как самостоятельный визуальный слой.

Не превращать его в обычную карточку.

## Mobile

Можно перейти к:

```text
БИЗНЕС-ЭКСПЕДИЦИЯ
ЮАР
дата
описание
CTA

стеклянный контур Африки
маршрут
точки
```

На mobile континент может стать меньше и уйти ниже текста.

**Прямоугольная glass-card не должна появляться снова.**

---

# 17. Предпочтительная техническая структура

```text
Hero
├── background-image
├── cinematic-overlay
├── navigation
├── content
│   ├── eyebrow
│   ├── title
│   ├── date
│   ├── description
│   └── CTA
│
└── expedition-map
    └── continent-glass-shape
        ├── glass-surface
        ├── continent-outline
        ├── route
        ├── markers
        └── labels
```

`expedition-map` не должен иметь собственного видимого прямоугольного контейнера.

---

# 18. SVG — предпочтительный вариант

Если возможно, использовать SVG.

Структура:

```text
SVG continent path
        ↓
mask / clipPath
        ↓
glass surface
        ↓
outline
        ↓
route
        ↓
markers
```

Это позволит получить именно **стеклянный силуэт**, а не glass-card с картой внутри.

---

# 19. Категорически не делать

- прямоугольную glass-card;
- карту внутри rounded rectangle;
- большую серую заливку;
- туристические pin-иконки;
- самолётики;
- компасы;
- декоративные глобусы;
- слишком яркий маршрут;
- огромные маркеры;
- отдельный card-footer;
- сильный blur всей карты;
- слишком слабый контур;
- dashboard/map UI;
- визуально самостоятельную карточку, оторванную от фотографии.

---

# 20. Критерий готовности

При первом взгляде должно возникать ощущение:

> **«Это не сайт турагентства. Это визуальная карта бизнес-экспедиции, наложенная на реальную экономическую среду страны».**

Пользователь должен мгновенно увидеть:

**ЮАР → бизнес-экспедиция → точки маршрута → возможность стать участником.**

Главный критерий:

### Правая часть должна читаться как

**СТЕКЛЯННЫЙ КОНТУР АФРИКИ**

а не как

**СТЕКЛЯННАЯ КАРТОЧКА С АФРИКОЙ.**

---

# 21. Финальная проверка

- [ ] Hero занимает 100vh.
- [ ] Фотография остаётся главным фоном.
- [ ] Левая композиция сохранена.
- [ ] Прямоугольная glass-card полностью удалена.
- [ ] Сам силуэт Африки является glass-объектом.
- [ ] Контур хорошо читается.
- [ ] Контур не превращён в непрозрачную карту.
- [ ] Точки находятся на континенте.
- [ ] Маршрут находится на/внутри континента.
- [ ] Оранжевый используется как акцент.
- [ ] Маркеры не выглядят туристическими.
- [ ] Нет отдельного card-footer.
- [ ] Карта стала крупным визуальным элементом.
- [ ] Карта не конкурирует с «ЮАР».
- [ ] Нет ощущения dashboard/map UI.
- [ ] На mobile не появляется прямоугольная glass-card.
- [ ] Эффекты остаются сдержанными и premium.

---

## Главное указание агенту

**Не улучшать текущую стеклянную карточку. Изменить саму метафору.**

Сейчас:

> `glass card → map`

Нужно:

> `map / continent → glass object`

Это принципиальное изменение данного Hero.
