# Блок «Наша позиция» — финальная инструкция для AI-агента

## 0. Цель

Переработать **только блок «Наша позиция»** на главной странице.

Задача — убрать ощущение пустого текстового полотна, но не превращать
его в стандартную AI-карточку, hero, bento-grid или обычный
`text + image`.

Визуальный характер: - тёплый светлый фон; - крупная рукописная
типографика; - чёрный основной текст; - фирменный оранжевый только как
акцент; - много воздуха; - тонкая вертикальная линия; - справа — почти
призрачный цветной редакционный набросок; - никакого стеклянного
контейнера вокруг всего блока.

------------------------------------------------------------------------

## 1. Текст — НЕ менять

**Метка:**

`НАША ПОЗИЦИЯ`

**Основной текст:**

`Мы не организуем туристические поездки. Мы проводим бизнес-экспедиции. Результат — ваше взвешенное решение об экспансии.`

**Правила:** - весь основной текст — чёрный/очень тёмный; - только
`бизнес-экспедиции` — фирменный оранжевый; - `бизнес-экспедиции`
подчеркнуть; - не окрашивать весь текст в оранжевый; - не делать весь
текст жирным; - использовать существующий фирменный рукописный шрифт
проекта.

Подпись:

`FExperience by Forbes Russia`

------------------------------------------------------------------------

Иллюстрация не должна выглядеть отдельной карточкой. Она является частью

------------------------------------------------------------------------

## 3. Изображение

Использовать подготовленную иллюстрацию:

`position-illustration.webp`

Если файл в проекте имеет другое имя — использовать фактический файл, но
сохранить эту концепцию.



Смысл изображения:

**исследование → контакты → понимание рынка → решение**

а не:

**путешествие → туризм → отдых**.

------------------------------------------------------------------------

## 4. Изображение должно быть очень бледным

Это ключевой пункт.

Картинка должна обнаруживаться примерно со второго взгляда.

Рекомендуемый CSS:

``` css
.position-section__illustration {
  opacity: 0.08;
  filter:
    blur(1.5px)
    saturate(0.65)
    contrast(0.9);
}
```

Допустимый диапазон opacity:

``` text
0.06 — если картинка слишком заметна
0.08 — базовое значение
0.10 — если картинка почти исчезает
```

Не использовать сильный blur. Нужен эффект выцветшего редакционного
рисунка, а не размытой фотографии.

------------------------------------------------------------------------

## 5. Визуальная иерархия

Приоритет элементов:

1.  основной рукописный текст;
2.  оранжевый акцент `бизнес-экспедиции`;
3.  `НАША ПОЗИЦИЯ`;
4.  тонкая вертикальная линия;
5.  иллюстрация;
6.  подпись.

Иллюстрация никогда не должна становиться главным объектом.

------------------------------------------------------------------------

## 8. Рукописная типографика

Основной текст обязательно оставить рукописным.

Если в проекте уже есть фирменный handwriting font — использовать его.

Не заменять его на: - Playfair Display; - Cormorant; - Georgia; -
обычный serif.

Если существующий глобальный font token уже задаёт handwriting font, не
переопределять его новым шрифтом.

------------------------------------------------------------------------

## 9. Не делать весь блок стеклянной карточкой

Не добавлять вокруг блока:

``` css
backdrop-filter: blur(...);
border-radius: 32px;
box-shadow: ...;
background: rgba(...);
```

Этот блок специально отличается от стеклянных элементов других частей
сайта.

Его характер:

**редакционный / авторский / бумажный / интеллектуальный.**

Глубину создаёт иллюстрация и её прозрачность.

------------------------------------------------------------------------

## 10. Фон

Использовать существующий тёплый фон сайта.

Ориентир:

``` css
background: #fff8f2;
```

Не использовать чистый белый `#ffffff`.

Не добавлять отдельный декоративный градиент, если глобальный фон уже
соответствует рестайлу.

------------------------------------------------------------------------

## 11. Glow

Для этого блока не нужен заметный glow.

Не использовать:

``` css
box-shadow: 0 0 50px rgba(255, 100, 43, 0.3);
```

Живость должна идти от: - акварельных пятен; - тонких линий; -
прозрачности; - рукописной типографики; - текстуры рисунка.

------------------------------------------------------------------------

## 12. Responsive

На мобильном не пытаться буквально сохранить десктопную композицию.

``` css

  }

  .position-section__title {
```

На мобильном текст остаётся главным. Иллюстрация может уйти ниже текста
и стать ещё менее заметной.

------------------------------------------------------------------------

## 13. Анимация

Если в проекте уже есть reveal-анимации, можно использовать очень
спокойное появление:

``` css
.position-section__illustration {
  opacity: 0;
  transform: translate3d(12px, 0, 0);
  transition:
    opacity 1.2s ease,
    transform 1.4s cubic-bezier(.22, .61, .36, 1);
}

.position-section.is-visible .position-section__illustration {
  opacity: 0.08;
  transform: translate3d(0, 0, 0);
}
```

Не делать постоянное движение.

Запрещены: - floating; - бесконечный parallax; - мерцание; -
пульсация; - glowing animation.

------------------------------------------------------------------------

## 14. Что нельзя менять

В рамках этой задачи НЕ менять: - текст блока; - смысл блока; -
глобальный фон сайта; - глобальную цветовую систему; - существующий
handwriting font; - соседние блоки; - структуру страницы; - таймер; -
блок регионов; - блок экспедиций; - Final CTA.

Это локальный рестайл только блока **«Наша позиция»**.

------------------------------------------------------------------------

## 15. Критерии приёмки

После реализации проверить:

### Тест 1 — текст

Если закрыть правую половину экрана, текст всё равно должен выглядеть
завершённым и сильным.

### Тест 2 — изображение

Если закрыть текст, иллюстрация не должна выглядеть самостоятельным
рекламным баннером.

### Тест 3 — иерархия

Сначала читается:

**НАША ПОЗИЦИЯ → рукописный текст → бизнес-экспедиции**

и только затем замечается рисунок.

### Тест 4 — прозрачность

Иллюстрация должна быть заметна только после первого взгляда.

### Тест 5 — стиль

Блок не должен выглядеть как: - AI landing page; - bento; - SaaS; -
туристический сайт; - стандартный editorial hero; - glassmorphism card.

------------------------------------------------------------------------

## 16. Финальная формула

Не:

**текст + картинка**

Не:

**glass card + image**

Не:

**AI illustration + marketing copy**

А:

**редакционный текст + авторская рукопись + полевой бизнес-скетч + много
воздуха.**

Именно это должно сохранить индивидуальный характер FExperience и общий
язык рестайла.
