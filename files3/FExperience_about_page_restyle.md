# FExperience — рестайлинг страницы «О нас»

## Назначение

Инструкция для AI-агента по переработке **только страницы «О нас»** в рамках нового визуального языка FExperience.

Не копировать главную страницу один в один. Нужно сделать «О нас» частью той же дизайн-системы, но с собственной драматургией:

- Главная — FExperience как идея и первое впечатление.
- О нас — FExperience как люди, метод и позиция.
- Экспедиция — FExperience как погружение в конкретный рынок.
- «Скоро» — FExperience как ожидание следующего рынка.
- Статьи — FExperience как редакция и знание.

---

# 1. Главный принцип

Текущая страница выглядит как обычная корпоративная страница: hero → текст → галерея → список преимуществ → команда → footer.

Нужно перейти от:

> «корпоративная страница о компании»

к:

> **«редакционный манифест о том, кто мы, зачем существуем и как проводим бизнес-экспедиции»**

Страница должна ощущаться как качественный деловой editorial-проект, а не SaaS/corporate landing page.

---

# 2. Визуальный DNA

Использовать уже сформированный на главной визуальный язык.

## Фон

- тёплый молочный / бумажный;
- не чисто белый;
- очень лёгкая зернистость / paper noise;
- без очевидного декоративного паттерна.

Noise почти незаметный. Его задача — создать ощущение материальной поверхности.

Если глобальный noise уже существует в проекте — использовать его, а не создавать второй.

Пример:

```css
.page {
  background: #f8f2eb;
  position: relative;
}

.page::before {
  content: "";
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: 9999;
  opacity: 0.025;
  background-image: url("data:image/svg+xml,...");
  mix-blend-mode: multiply;
}
```

## Цвета

```css
--paper: #f8f2eb;
--paper-soft: #fbf7f2;
--ink: #171717;
--muted: #8f8a84;
--line: rgba(35, 30, 25, 0.12);
--accent: #ff5a2a;
```

Оранжевый — **сигнал, а не основной цвет текста**.

Использовать его для:

- section labels;
- отдельных смысловых слов;
- тонких линий;
- маркеров;
- hover;
- небольших UI-акцентов.

---

# 3. Типографика

Использовать существующий serif-шрифт проекта для:

- крупных заголовков;
- editorial headlines;
- крупных цифр;
- ключевых тезисов.

Рукописный шрифт — редкий смысловой инструмент.

**Не делать весь текст рукописным.**

---

# 4. Первый экран — «О нас»

## Проблема

Текущий hero:

> FExperience — новый проект команды Forbes Russia

с обычными поясняющими абзацами выглядит слишком corporate.

## Новая композиция

Сохранить смысл, но сделать его editorial:

```text
О НАС

FExperience — новый проект команды
Forbes Russia.

[короткое объяснение]

Мы помогаем предпринимателям открывать
новые горизонты на самых перспективных рынках.

[тонкая editorial-линия / небольшой акцент]
```

Заголовок крупнее текущего, больше воздуха.

**Не помещать hero в карточку.**

Не использовать стандартный gradient.

Не превращать hero в типичный SaaS-экран.

---

# 5. Editorial-манифест

После hero нужен сильный смысловой блок.

Использовать уже сформированный на главной принцип:

- слева вертикальная тонкая линия;
- маленький оранжевый label;
- крупный рукописный текст;
- одно смысловое слово выделяется фирменным оранжевым;
- справа — очень бледный цветной editorial-скетч.

Пример:

```text
Мы не организуем туристические поездки.
Мы проводим БИЗНЕС-ЭКСПЕДИЦИИ.
Результат — ваше взвешенное решение
об экспансии.
```

Правило цвета:

- основной handwritten text = почти чёрный;
- `БИЗНЕС-ЭКСПЕДИЦИИ` = orange;
- accent word можно подчеркнуть тонкой линией.

**Не делать весь рукописный текст оранжевым.**

---

# 6. Иллюстрация справа

Использовать созданное для этого блока изображение/иллюстрацию, находится в images/about/about-manifest-editorial-sketch.webp

Это должен быть:

> **очень лёгкий цветной editorial sketch**

Тематика:

- деловая встреча;
- предприниматели;
- исследование новой среды;
- разговор;
- город / рынок / движение;
- ощущение экспедиции.

Не изображать:

- детей;
- семейный туризм;
- туристическую группу;
- конкретный континент;
- конкретную страну;
- достопримечательность;
- самолёт как туристический символ;
- чемоданы и другие travel clichés.

## CSS-обработка

Изображение слабее текста:

```css
.about-manifest__illustration {
  opacity: 0.16;
  filter:
    saturate(0.72)
    contrast(0.86)
    blur(0.25px);
}
```

Можно добавить мягкую маску:

```css
mask-image: linear-gradient(
  to right,
  transparent 0%,
  rgba(0,0,0,.55) 25%,
  #000 55%,
  #000 100%
);
```

Главное правило:

> пользователь должен сначала прочитать манифест, а уже потом заметить изображение.

---

# 7. «Деловая программа и погружение в локальную культуру»

Смысл существующего контента сохранить:

- деловая программа;
- встречи;
- локальные предприниматели;
- эксперты;
- культурная среда;
- понимание рынка через присутствие.

## Новая подача

Не делать обычную схему:

```text
заголовок
текст
одна большая карточка
три маленькие карточки
```

Сделать **editorial photo essay**.

Большое изображение — главный якорь.

Остальные изображения — разного масштаба, с небольшими вертикальными смещениями.

Пример:

```text
┌─────────────────────┐       ┌──────────────┐
│                     │       │              │
│   LARGE PHOTO       │       │ SMALL PHOTO  │
│                     │       │              │
└─────────────────────┘       └──────────────┘
                              ┌──────────────┐
                              │              │
                              │ SMALL PHOTO  │
                              │              │
                              └──────────────┘
```

Не строить идеальную сетку.

Фото должны иметь единый editorial grade:

- тёплые;
- натуральные;
- без чрезмерной насыщенности;
- без stock-photo ощущения.

---

# 8. «Ключевое отличие FExperience»

Сохранить существующие 9 факторов:

1. Безопасность в стране
2. Деловой климат
3. Регуляторная среда
4. Особенности логистики
5. Реальный запрос бизнеса
6. Культурные барьеры
7. Финансовая инфраструктура
8. Цифровизация экономики
9. Стоимость выхода на рынок

## Проблема текущей версии

Сейчас это обычный feature-list.

Нужно превратить его в **редакционную классификацию факторов рынка**.

## Композиция

Слева:

```text
DUE DILIGENCE

Ключевое
отличие
FExperience
```

Справа — вертикальный список:

```text
01 / 09     ○     Безопасность в стране
────────────────────────────────────────
02 / 09     ○     Деловой климат
────────────────────────────────────────
03 / 09     ○     Регуляторная среда
```

Использовать:

- тонкие разделители;
- маленькую типографику номера;
- маленький оранжевый маркер;
- основной текст чёрный;
- много воздуха.

## Hover

При наведении:

- строка слегка смещается;
- маркер становится orange;
- появляется короткое пояснение;
- остальные строки остаются спокойными.

Не использовать тяжёлые accordion cards.

---

# 9. «Due diligence — основа нашей методологии»

Сохранить эту фразу как отдельный editorial statement:

```text
Due diligence —
основа нашей методологии.
```

Можно добавить тонкую горизонтальную линию.

Не превращать в CTA.

---

# 10. «Команда проекта»

## Проблема

Текущая схема:

```text
большая фотография
+
список имён и должностей
```

выглядит как стандартная corporate team section.

## Новая идея

Сохранить реальные фотографии, имена и должности, но показать людей как участников экспедиции, а не как оргструктуру.

Заголовок:

```text
КОМАНДА

Люди, которые ведут экспедицию
```

Если текущий заголовок нельзя менять из-за контента/CMS — оставить его.

## Композиция

Большой портрет слева.

Справа — список людей.

Пример:

```text
Денис Кошкин
Исполнительный директор Forbes Russia

[короткая editorial-фраза]
```

Если дополнительных фактов нет в проекте — **не придумывать их**. В таком случае оставить имя + должность, но сделать их типографически выразительнее.

Не использовать employee cards.

Не использовать одинаковые круглые аватары.

Портрет — большой, editorial, с небольшим radius и очень тонкой рамкой.

---

# 11. Секция между командой и footer

Не добавлять новый смысловой блок без необходимости.

Не раздувать страницу ради количества секций.

# 13. Общие правила для AI-агента

## Не делать

```text
❌ Не превращать страницу в SaaS landing page.
❌ Не использовать стандартные карточки преимуществ.
❌ Не использовать чрезмерные gradients.
❌ Не заливать секции оранжевым.
❌ Не делать весь текст рукописным.
❌ Не делать весь текст оранжевым.
❌ Не добавлять туристические клише.
❌ Не использовать случайные stock illustrations.
❌ Не добавлять новые факты о компании без источника.
❌ Не превращать фотографии в одинаковую grid.
❌ Не копировать главную страницу блок в блок.
```

## Сохранить

```text
✓ Существующий контент и фактические данные.
✓ Реальные фотографии.
✓ Реальные имена и должности.
✓ Список из 9 факторов due diligence.
✓ Навигацию.
✓ Общий brand accent — orange.
✓ SEO/контентную структуру, если она уже используется.
```

# 14. Адаптив

## Desktop

- editorial composition;
- большие поля;
- асимметричные изображения;
- крупная типографика.

## Tablet

- сохранить hierarchy;
- уменьшить ширину текстовых колонок;
- не превращать всё автоматически в одинаковые cards.

## Mobile

- manifest text остаётся главным;
- иллюстрацию уменьшить и увести под текст;
- photo essay становится вертикальным;
- due diligence остаётся читаемым;
- команда становится вертикальной;
- serif text не должен становиться слишком мелким.

Пример:

```css
@media (max-width: 768px) {
  .about-manifest {
    grid-template-columns: 1fr;
  }

  .about-manifest__illustration {
    position: absolute;
    right: 0;
    bottom: 0;
    width: 55%;
    opacity: 0.09;
  }

  .about-photoessay {
    grid-template-columns: 1fr;
  }

  .about-team {
    grid-template-columns: 1fr;
  }
}
```

# 15. Материальность

На всей странице использовать:

```text
warm paper background
+
very subtle noise
+
thin borders
+
soft shadows
+
editorial typography
+
real photography
+
restrained orange accents
```

Тени мягкие:

```css
box-shadow:
  0 20px 60px rgba(70, 45, 30, 0.05);
```

Не использовать сильные чёрные тени.

---

# 16. Критерий успеха

После реализации страница должна давать ощущение:

> «Это не корпоративная страница компании. Это редакционный материал о людях, которые исследуют новые рынки».

Пользователь при этом должен без труда понять:

1. кто такие FExperience;
2. чем они отличаются;
3. что такое бизнес-экспедиция;
4. как они работают;
5. кто стоит за проектом.

Визуально страница должна быть частью новой FExperience, но **не копией главной**.

---

# 17. Финальная проверка

Перед сдачей проверить:

- [ ] Первый экран выглядит editorial, а не corporate.
- [ ] Рукописный шрифт используется дозированно.
- [ ] Основной handwritten text чёрный.
- [ ] Только смысловой accent word — orange.
- [ ] Иллюстрация манифеста очень бледная.
- [ ] Иллюстрация не перетягивает внимание.
- [ ] Нет туристических клише.
- [ ] Photo essay не выглядит обычной grid.
- [ ] Due diligence выглядит как editorial classification.
- [ ] Команда не выглядит как стандартная employee-card section.
- [ ] Сохранены реальные данные и фотографии.
- [ ] Фон имеет лёгкую бумажную зернистость.
- [ ] Orange используется экономно.
- [ ] Тонкие линии и воздух выдержаны.
- [ ] Mobile сохраняет характер.
- [ ] Страница выглядит частью нового FExperience, но не копией главной.
