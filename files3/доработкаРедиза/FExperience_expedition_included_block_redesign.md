# FExperience — Детальная экспедиция: блок «Что включено»: инструкция AI-агенту (v2)

⚠️ v2 заменяет v1. Отличия: шапка блока (лейбл + подзаголовок) располагается
СЛЕВА в верхней части секции; шесть пунктов идут НИЖЕ шапки НА ВСЮ ширину
блока, а не в правой колонке. Заголовок оформляется стандартным
лейблом (eyebrow), как в других блоках страницы.

## 0. Задача

Собрать светлый блок «Что включено» на `/expeditions/[slug]`: сверху слева —
лейбл раздела и подзаголовок; ниже на всю ширину — шесть пунктов состава
экспедиции с line-иконками (состав исходного сайта). Две панели («Для кого
эта экспедиция» + «Организационные детали») НЕ делать.

Палитра — нейтральная бумага: фон секции `--color-surface` (#F1E3D8),
текст `--color-text-primary` / `--color-text-secondary`,
orange `--color-brand-600` (только лейбл).

Старый слайдер «Что включено» (IncludedSlider на Embla) НЕ используется:
шесть пунктов — статичная сетка, без стрелок и свайпа.

## 1. Тексты — зафиксированы

- Лейбл (eyebrow): `Что включено`
  (рендер в uppercase через text-transform, как все лейблы системы)
- Подзаголовок (под лейблом, в левой части):
  `Мы полностью берём на себя организацию экспедиции и решение всех операционных вопросов. Вы занимаетесь бизнесом и нетворкингом — обо всём остальном позаботится команда FExperience.`

Шесть пунктов (порядок и состав — исходный сайт):
1. `Медийное сопровождение`
2. `Бизнес-сессии, нетворкинг`
3. `Культурные мероприятия`
4. `Проживание в отеле 5*`
5. `Трансферы вип-класса`
6. `Питание`

Источник строк — поле `expedition.includes` из `src/data/expeditions.ts`.
Рендерить как есть, без text-transform. Если формулировки в данных
отличаются от списка выше — привести строки данных к списку
(правка контента утверждена), структуру данных не менять.

## 2. Точные визуальные параметры

### Секция
```css
.expedition-included {
  background: var(--color-surface);      /* #F1E3D8 */
  padding: 96px 0;                       /* 56px mobile */
}
.expedition-included__container {
  max-width: 1280px;
  margin: 0 auto;
  padding-inline: 64px;                  /* 32 tablet / 24 mobile */
}
```

### Шапка блока — СЛЕВА в верхней части
```css
.included-head {
  max-width: 560px;                      /* занимает левую часть, не всю строку */
}
.included-label {
  font: 600 12px HelveticaNeueCyr;
  letter-spacing: .1em;
  text-transform: uppercase;
  color: var(--color-brand-600);         /* стандартный лейбл системы */
}
.included-subtitle {
  margin-top: 16px;
  font: 400 15.5px/1.65 HelveticaNeueCyr;
  color: var(--color-text-secondary);
}
```
- Крупного serif-H2 в блоке НЕТ: заголовок = лейбл (как «НАША МЕТОДОЛОГИЯ»,
  «НАС ВЫБИРАЮТ ЗА» в других блоках).
- Справа от шапки — воздух; никаких дополнительных элементов, стрелок,
  номеров, CTA.

### Шесть пунктов — НИЖЕ шапки, НА ВСЮ ширину блока
```css
.included-items {
  margin-top: 56px;                      /* 40px mobile */
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 × 2 на desktop */
  gap: 40px 48px;
}
.included-item {
  display: flex;
  align-items: flex-start;
  gap: 14px;
}
.included-item svg {
  width: 28px; height: 28px;
  stroke-width: 1.25; fill: none;
  color: var(--color-text-primary);
  opacity: .8;
  flex-shrink: 0;
  margin-top: 2px;
}
.included-item__name {
  font: 600 15px/1.45 HelveticaNeueCyr;
  color: var(--color-text-primary);
}
```
- Пункты — без карточек: нет background, border, radius, shadow.
- Разделение — только воздух сетки; без hairline между пунктами.

### Иконки (Lucide, единый линейный стиль, маппинг спеки 13.8)

- Hover отсутствует — статичный editorial-блок.

## 3. Что сохранить / не трогать

- Данные `expedition.includes` как источник строк.
- Тёмную «Программу экспедиции» выше и блоки ниже (эксперты, CTA, FAQ) —
  собираются отдельными инструкциями.
- JSON-LD, Header/Footer, RequestModal.

## 4. Что запрещено

- Двухколоночная композиция «шапка слева / пункты справа» (ошибка v1):
  пункты идут ПОД шапкой на всю ширину.
- Крупный serif-H2 вместо лейбла; оранжевые слова внутри заголовка.
- Две панели «Для кого эта экспедиция» и «Организационные детали».
- Слайдер/карусель (Embla), стрелки prev/next, свайп.
- Четыре пункта вместо шести; выдуманные седьмой+ пункты.
- Карточки вокруг пунктов: background, border, radius, shadow, glass.
- Фото-фоны пунктов (included-bg-*.webp в этом блоке не нужны).
- Uppercase-трансформация названий пунктов (uppercase только у лейбла).
- Оранжевые иконки.
- Тёмный фон секции.
- Переписывание подзаголовка из раздела 1.
- Изменения соседних блоков.

## 5. Responsive

- ≤1024px: `.included-items { grid-template-columns: 1fr 1fr; }`
  шапка max-width 100%; padding-inline 32px.
- ≤640px: `.included-items { grid-template-columns: 1fr; gap: 24px; }`
  padding секции 56px 0; padding-inline 24px; подзаголовок 15px.

## 6. Критерии готовности

Блок читается как спокойный светлый «слой бумаги»: сверху слева — оранжевый
лейбл «ЧТО ВКЛЮЧЕНО» и подзаголовок про операционную заботу команды; ниже
на всю ширину — шесть пунктов с тонкими линейными иконками в сетке 3×2.
Без слайдера, без панелей, без карточек, без правой колонки.
