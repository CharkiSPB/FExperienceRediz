# FExperience — Hero: инструкция AI-агенту

## Задача
Точечно переработать Hero главной страницы, не меняя остальные секции и не создавая новый дизайн с нуля.

Сохранить:
- Hero `100vh`;
- левую стеклянную область;
- правый видео/фотофон;
- существующие CTA;
- существующую механику слайдера.

## 1. Заголовок
Уменьшить заголовок так, чтобы **он полностью помещался внутри левой стеклянной части** и не пересекал границу с изображением.

Над ним оставить три существующих тезиса/pills.

Пример:
```text
[ тезис ] [ тезис ] [ тезис ]

Бизнес-экспедиция
в ЮАР

[ CTA ] [ CTA ]
```

`Бизнес-экспедиция` — чёрный / существующий основной тёмный цвет.

`в ЮАР`, `во Вьетнам` или название направления текущего слайда — фирменный orange.

Не красить весь заголовок в orange.

## 2. CTA
Кнопки **не redesign**:
- сохранить тексты;
- размеры;
- цвета;
- стиль;
- функциональность.

Можно только слегка изменить их положение после уменьшения заголовка.

## 3. Новая круглая печать
Добавить крупную, очень лёгкую **полупрозрачную круглую Forbes FExperience печать** на границе:

**СТЕКЛО | VIDEO/PHOTO**

Примерно половина печати должна находиться на стекле, половина — на видео/фото.

Она должна физически пересекать две поверхности.

Печать — это не карточка и не UI-badge.

### Внешний вид
- тонкая круглая линия;
- прозрачная/полупрозрачная;
- editorial / rubber-stamp характер;
- без плотной заливки;
- без neon;
- без сильного glow;
- без тяжёлой тени.

Материал под печатью должен просматриваться.

## 4. Текст печати
По окружности повторяется:

`FORBES FEXPERIENCE`

Между повторами:

`·`

Логика:
```text
FORBES FEXPERIENCE · FORBES FEXPERIENCE · FORBES FEXPERIENCE ·
```

Текст идёт по окружности. Сохранить аккуратный tracking и равномерный spacing.

## 5. Центр печати
В центре:

`F`

Буква `F` — фирменного orange.

Оранжевой должна быть именно центральная F, а не вся печать.

## 6. Управление слайдером — ОБЯЗАТЕЛЬНО
**Не удалять и не скрывать существующие кнопки управления слайдером.**

Сохранить:
- Previous;
- Next;
- pagination / индикаторы;
- progress line, если существует;
- autoplay;
- swipe/touch на mobile, если уже реализован.

Допускается только аккуратно скорректировать позицию controls, если они конфликтуют с новой печатью, CTA или заголовком.

После реализации проверить:
```text
Previous → работает
Next → работает
Autoplay → работает
Pagination / indicator → работает
Swipe / touch → работает на mobile
```

Не заменять существующую механику слайдера без необходимости.

## 7. Визуальная иерархия
1. Заголовок
2. Видео/фотография
3. Три тезиса
4. CTA
5. Печать
6. Slider controls

Печать должна обнаруживаться чуть позже первого взгляда и добавлять характер, а не конкурировать с заголовком.

## 8. Responsive

### Desktop
Сохранить горизонтальную композицию. Печать пересекает границу стекла и изображения.

### Tablet
Пропорционально уменьшить заголовок и печать. Не позволять печати перекрывать текст.

### Mobile
Если Hero становится вертикальным, сохранить идею печати на границе двух материалов. Уменьшить печать и сохранить:
- 3 тезиса;
- заголовок;
- CTA;
- slider controls.

## 9. Что НЕ менять
Не:
- возвращать огромный заголовок на всю ширину;
- красить весь заголовок в orange;
- красить `Бизнес-экспедиция` в orange;
- переносить заголовок на видео;
- превращать pills в большие карточки;
- делать печать непрозрачной;
- делать всю печать orange;
- превращать печать в UI badge;
- добавлять новый логотип;
- добавлять новые CTA;
- удалять slider controls;
- ломать autoplay;
- ломать Previous/Next;
- удалять pagination;
- ломать mobile swipe;
- менять остальные секции сайта.

## Критерий готовности
Hero должен ощущаться как **дорогой editorial cover**, где стекло, видео и фирменная Forbes FExperience печать взаимодействуют как физические материалы.

Первый взгляд:
**3 тезиса → Бизнес-экспедиция → направление → CTA**

Второй взгляд:
**полупрозрачная круглая печать, пересекающая границу стекла и изображения.**

## Главное указание агенту
**Не создавать новый дизайн Hero.**

Точечно пересобрать существующий:

> **3 тезиса → компактный двухцветный заголовок внутри стекла → существующие CTA → полупрозрачная Forbes FExperience печать на границе стекла и видео → сохранённое полноценное управление слайдером.**

Печать должна выглядеть так, будто **один физический фирменный штамп одновременно находится на двух разных материалах — стекле и фотографии.**
