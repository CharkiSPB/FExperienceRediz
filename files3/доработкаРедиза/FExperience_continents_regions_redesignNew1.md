## 0. Задача

Блок регионов — НЕ грид 2×2. На desktop это четыре компактные карточки
В ОДНУ ГОРИЗОНТАЛЬНУЮ СТРОКУ, как на референсе. Внутри карточки —
вертикальная композиция референса: карта сверху → название → описание →
круглая стрелка внизу справа. Уйти от больших карточек с картой справа.

## 1. Сетка

```css
.region-row {
  display: grid;
  grid-template-columns: repeat(4, 1fr);   /* одна горизонтальная строка */
  gap: 16px;
}
@media (max-width: 1024px) { .region-row { grid-template-columns: 1fr 1fr; } }
@media (max-width: 640px)  { .region-row { grid-template-columns: 1fr; } }
```
2×2 — ТОЛЬКО на tablet как промежуточный брейкпоинт; desktop ≥1025px —
строго четыре в ряд. Mobile — одна колонка.

## 2. Карточка — композиция референса

```css
.region-card {
  position: relative;
  display: flex;
  flex-direction: column;
  padding: 20px 20px 18px;
  border-radius: 10px;
  background: linear-gradient(135deg, rgba(255,241,229,.7), rgba(242,223,206,.45));
  border: 1px solid rgba(184,111,87,.14);
}
.region-card__num  { font: 600 11px HelveticaNeueCyr; letter-spacing: .08em;
                     color: rgba(184,111,87,.65); margin-bottom: 8px; }
.region-card__map  { height: 110px; margin-bottom: 14px; }   /* карта СВЕРХУ */
.region-card__name { font: 600 20px/1.15 var(--font-display);
                     color: var(--text-primary); }
.region-card__desc { font: 400 12.5px/1.5 HelveticaNeueCyr;
                     color: var(--text-secondary); margin-top: 6px; }
.region-card__arrow {
  margin-top: auto;                 /* прижата к низу карточки */
  align-self: flex-end;             /* справа */
  width: 32px; height: 32px; border-radius: 50%;
  background: var(--orange-600); color: #fff;
  display: grid; place-items: center;
  margin-top: 14px;
  transition: transform .3s var(--ease);
}
.region-card__arrow svg { width: 14px; height: 14px; }
```

- Карта — сверху карточки, height 110px desktop / 120px mobile; терракота
  и точки — по базовому файлу (fill .12→.20 hover, stroke .55→.80).
- Название и описание — под картой, слева.
- Круглая стрелка 32px — внизу справа (как на референсе), НЕ текст
  «Смотреть →».
- Номер 01–04 — маленький сверху слева (editorial rhythm из базового
  файла); не конкурирует с картой.
- Вся карточка кликабельна → директория с фильтром по региону
  (существующая логика ссылок).
