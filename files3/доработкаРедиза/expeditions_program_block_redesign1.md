# FExperience — Блок «Ближайшая экспедиция + программа»: инструкция AI-агенту (v2)

⚠️ v2 заменяет v1 полностью. Причина: v1 был реализован как две скруглённые
карточки с полями и заголовком на светлом фоне. Референс — ОДИН full-bleed
элемент из двух половин вплотную, весь контент внутри.

## 0. Задача

Собрать блок как единый полноэкранный элемент без отступов и скруглений:
- ЛЕВАЯ половина — full-bleed фото ближайшей экспедиции + существующая
  glass-карточка (название, дата, CTA) внизу слева.
- ПРАВАЯ половина — единая тёмная тёплая поверхность: eyebrow
  «БЛИЖАЙШИЕ ЭКСПЕДИЦИИ», заголовок «Бизнес начинается там, где
  заканчивается знакомое.», короткий контекстный абзац и три preview
  дней программы внизу.

Не создавать новый дизайн с нуля: данные, glass-card и тексты — существующие.

## 1. Геометрия блока — один элемент, без отступов

```css
.program-block {
  width: 100%;                 /* от края до края viewport */
  display: grid;
  grid-template-columns: 48fr 52fr;
  min-height: 600px;           /* desktop */
  border-radius: 0;            /* НИКАКИХ скруглений блока */
  overflow: hidden;
}
```
- Нет max-width, нет внешних margin/padding, нет gap между половинами.
- Половины соприкасаются по прямой вертикальной границе.
- Светлого фона вокруг блока НЕТ: блок не стоит «карточкой» на кремовой
  секции. Секция над блоком не содержит заголовка/eyebrow этого блока.

## 2. Левая половина — фото + glass-card

```css
.program-block__media { position: relative; overflow: hidden; }
.program-block__media img {
  position: absolute; inset: 0;
  width: 100%; height: 100%;
  object-fit: cover;
  border-radius: 0;            /* фото full-bleed, без скруглений */
}
.program-block__card {
  position: absolute;
  left: 32px; bottom: 32px;
  max-width: 340px;
  /* существующий glass-компонент, не перерисовывать */
}
```
- Фото — существующее изображение ближайшей экспедиции (сохранить логику
  `image` / `imageEvening`, если она есть).
- Glass-card сохранить существующую: label («Ближайшая экспедиция» /
  статус), название страны (Playfair, крупно), дата с иконкой, CTA-кнопка.
  Тексты и кнопку НЕ переписывать.
- Карточка — внизу слева на фото, не по центру, не на всю ширину.

## 3. Правая половина — единая тёмная поверхность

```css
.program-block__panel {
  background: #261D18;         /* глубокий тёплый графит, НЕ #000 */
  padding: 56px 64px 48px;
  display: flex;
  flex-direction: column;
}
```
Порядок контента сверху вниз (всё ВНУТРИ тёмной половины):

1. Eyebrow: `БЛИЖАЙШИЕ ЭКСПЕДИЦИИ`
   — цвет как сейчас (оранжевый, `--orange-600`), uppercase,
     12px, letter-spacing .1em.
2. H2: `Бизнес начинается там, где заканчивается знакомое.`
   — Playfair Display 600, clamp(28px, 2.6vw, 40px)/1.2,
     color #FFF6EE; margin: 16px 0 20px.
3. Абзац — существующий короткий контекст о регионе/экспедиции
   (из текущих данных, НЕ переписывать):
   14.5px/1.6 HelveticaNeueCyr, color rgba(255,246,238,.68),
   max-width 520px.
4. Три preview дней — горизонтальный ряд, прижат к низу панели
   (`margin-top: auto`, минимум 40px от абзаца).

ЗАПРЕЩЕНО: ставить описание Дня 1 (или любого дня) крупным заголовком
правой половины — ошибка реализации v1. Дни живут ТОЛЬКО в трёх preview.

## 4. Preview дней программы

```css
.program-days {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 14px;
  margin-top: auto;
  padding-top: 40px;
}
.program-day__img {
  width: 100%;
  aspect-ratio: 16 / 10;
  object-fit: cover;
  border-radius: 8px;          /* скругление только у маленьких фото */
}
.program-day__num {
  margin-top: 12px;
  font: 600 11px HelveticaNeueCyr;
  letter-spacing: .1em;
  text-transform: uppercase;
  color: var(--orange-600);
}
.program-day__text {
  margin-top: 6px;
  font: 400 12.5px/1.5 HelveticaNeueCyr;
  color: rgba(255,246,238,.72);
}
```
- Карточки preview прозрачны на тёмном фоне: без собственного background,
  border, shadow.
- Данные: первые 3 дня программы ближайшей экспедиции из `src/data`
  (`programs[programSlug]`). Дней меньше — показывать сколько есть;
  фиктивные дни НЕ создавать.
- Hover: мягкий zoom изображения (scale 1.03, 300–400ms), без подъёма.

## 5. Динамика (сохраняется из v1)

- Главная экспедиция = ближайшая будущая по дате из `src/data`;
  ЮАР/Вьетнам НЕ хардкодить.
- При смене главной экспедиции меняются: фото, название, дата, CTA-ссылка,
  eyebrow-регион (если используется в абзаце), контекстный абзац,
  превью дней (изображения, номера, описания).
- Не создавать параллельную data-логику.

## 6. Responsive

- ≤1024px: `grid-template-columns: 1fr 1fr`; padding панели 40px 32px;
  H2 26–28px.
- ≤767px: одна колонка. Сверху — фото с glass-card (height 440px),
  ниже — тёмная панель (padding 32px 24px). Preview дней —
  горизонтальный scroll-snap: `grid-auto-flow: column; overflow-x: auto;
  scroll-snap-type: x mandatory;` карточка `min-width: 72%`.
  Тёмный фон объединяет текст и preview. Glass-card остаётся первым
  визуальным элементом слева/сверху.

## 7. Что НЕ делать

- Скругления блока и половин; внешние отступы/поля; gap между половинами;
  «карточка на светлом фоне» вместо full-bleed элемента.
- Eyebrow и H2 на светлом фоне вне блока.
- Текст дня крупным заголовком правой половины.
- Отдельные тёмные карточки вокруг каждого preview.
- Переписывание существующих текстов (glass-card, абзац, дни).
- Чистый #000 в правой половине; неон и glow.
- Изменения соседних секций.
