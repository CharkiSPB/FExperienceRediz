# FExperience — Блок статистики после Hero (Market Reality): инструкция AI-агенту

## 0. Задача

Переработать блок статистики сразу после Hero в единую горизонтальную полосу
из трёх равных колонок: line-иконка слева, крупная serif-цифра, название и
короткое описание под ней.

Разделение колонок — НЕ линией. Каждая колонка имеет собственный горизонтальный
градиент: слева — более глубокий тон фона, справа — полное растворение в
основной цвет фона. «Ступенька» сброса градиента между соседними колонками и
есть мягкий разделитель.

Визуальный референс: скриншот полосы ([icon] цифра / лейбл / описание,
три колонки с лево-правым градиентом). КОНТЕНТ БРАТЬ НЕ ИЗ РЕФЕРЕНСА —
использовать настоящие метрики (раздел 1 ниже).

Приоритеты:
- Контент (цифры, формулировки) — раздел 2.2
  `FExperience_Build_Spec_AI_Agent_FINAL_CLEAN.md`.
- Визуальная композиция (равные колонки, иконки, градиентное разделение) —
  этот файл. Асимметрия 40/30/30 и hairline-разделители из 2.2 НЕ используются.

Фоновая система сайта (#FFF1E5 + #F2DFCE) уже внедрена отдельной инструкцией.
Здесь её НЕ пересоздаём — только используем значения.

## 1. Что именно изменить

- Блок = три равные колонки в одной полосе, `gap: 0`.
- Каждая колонка: line-иконка слева; справа от неё цифра; под цифрой —
  название и короткое описание.
- Фон каждой колонки: `linear-gradient(to right, #F2DFCE 0%, #FFF1E5 100%)`.
  Правый край колонки точно совпадает с основным фоном секции; левый край
  следующей колонки снова начинается с #F2DFCE — этот тоновый сброс является
  единственной границей между колонками.
- Никаких линий, `border-left`, псевдоэлементов-разделителей, рамок, теней,
  скруглений.

Контент (фиксирован, формулировки из спеки 2.2, не переписывать):

| Цифра | Название            | Описание                                       |
|-------|---------------------|------------------------------------------------|
| >60%  | неудачных экспансий | из-за недостаточно глубокого анализа рынка     |
| 50+   | лояльных контактов  | минимум для понимания специфики рынка          |
| >40%  | стартапов терпят провал | из-за невостребованности продукта          |

## 2. Точные визуальные параметры

### Секция
- Фон секции: `#FFF1E5` (основной фон сайта из внедрённой фоновой системы).
- Собственной текстуры у полосы нет: глобальный бумажный noise основного фона
  продолжает работать; второй noise поверх градиента НЕ добавлять.
- padding-block: 72px desktop / 56px mobile.
- Контейнер: max-width 1280px; padding-inline: 64px / 32px / 24px.

### Колонки и градиентное разделение
```css
.stats-band {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 0;
}
.stat-col {
  position: relative;
  padding: 40px 48px 40px 40px;
  background: linear-gradient(to right, #F2DFCE 0%, #FFF1E5 100%);
  display: grid;
  grid-template-columns: 28px 1fr;   /* иконка | контент */
  column-gap: 20px;
  align-items: start;
}
```
- НЕ добавлять `::before` / `::after` разделители, `border-left` и любые
  вертикальные линии.
- Градиент колонки обязан заканчиваться ТОЧНО `#FFF1E5` — колонка растворяется
  в фоне секции.
- Следующая колонка начинается заново с `#F2DFCE` — тоновая ступенька между
  ними и есть задуманный разделитель. НЕ сглаживать её общим градиентом на всю
  полосу и НЕ вставлять промежутки между колонками.

### Колонка
- Иконка: 28px, `stroke-width: 1.25`, `fill: none`, color `rgba(26,26,26,.65)`,
  `margin-top: 6px`. Никаких кругов/квадратов/подложек вокруг иконки.
- Цифра: `font: 700 56px/1 'Playfair Display', serif; color: var(--text-primary);
  letter-spacing: -.02em;` Знаки `>`, `%`, `+` — `--orange-700`; сами цифры
  тёмные, НЕ оранжевые.
- Название: `font: 600 15px HelveticaNeueCyr; color: var(--text-primary);
  margin-top: 10px;`
- Описание: `font: 400 13.5px/1.55 HelveticaNeueCyr; color: var(--text-secondary);
  margin-top: 6px; max-width: 34ch;`

Схема:

```
[icon]   >60%
         неудачных экспансий
         из-за недостаточно глубокого анализа рынка
```

### Иконки (Lucide, единый линейный стиль)
- `>60%` — `Compass` (экспансии / выход на рынки)
- `50+`  — `Handshake` (лояльные контакты)
- `>40%` — `TrendingDown` (провал стартапов)

`<Icon size={28} strokeWidth={1.25} />`, `aria-hidden="true"`.
Стиль обязан совпадать с референсом: тонкий line-art, без заливки.

### Анимации
- Цифры: существующий `StatCounter` (countup.js, раздел 15.5 спеки);
  для `>60%` и `>40%` использовать prefix/suffix countup.js
  (`prefix: '> '`, `suffix: '%'` / `suffix: '+'`), duration 1.8,
  scrollSpyOnce. Кастомный счётчик НЕ писать.
- Появление колонок: `.fade-up` + `.delay-1 / .delay-2 / .delay-3`
  (глобальный хук `useScrollReveal`). Framer Motion НЕ использовать.
- Hover: отсутствует полностью. Это информационная полоса, не карточки.

## 3. Что сохранить

- Позицию блока: сразу после Hero, перед следующей секцией.
- Формулировки метрик из спеки 2.2 без переписывания.
- Внедрённую фоновую систему `#FFF1E5` / `#F2DFCE` как есть.
- Hero, header, footer и все соседние секции — без изменений.
- Тёмный блок «Программа / Спикеры / Участники» (раздел 10.5) — ДРУГОЙ блок,
  не трогать и не объединять со статистикой.

## 4. Что запрещено

- Любые разделители между колонками: сплошные линии, hairline, вертикальные
  градиентные линии, `border-left`. Разделение — только сбросом
  лево-правого градиента каждой колонки.
- Общие градиенты на всю полосу вместо трёх поколоночных.
- Карточки: белые/стеклянные подложки, `border-radius`, `box-shadow`, рамки.
- Glassmorphism, glow, неон, тяжёлые тени.
- Иконки >32px, иконки в контейнерах, заливка иконок orange.
- Оранжевые цифры целиком (orange — только знаки `>`, `%`, `+`).
- Цифры из референса (60+ экспедиций / 50+ экспертов / 40+ городов) —
  только настоящие метрики 2.2.
- H2, eyebrow, CTA внутри полосы.
- Переписывание текстов, изменение соседних секций.

## 5. Responsive

- ≤1024px: три колонки сохраняются; цифра 44px; иконка 24px;
  padding колонок 28px 24px.
- ≤767px: вертикальный стек, `gap: 0`; градиент каждой строки становится
  вертикальным, сохраняя логику «тон → растворение в основной фон»:
  ```css
  .stat-col {
    background: linear-gradient(to bottom, #F2DFCE 0%, #FFF1E5 100%);
    padding: 28px 24px;
  }
  ```
  Внутренняя схема сохраняется (иконка слева, цифра справа, название/описание
  под цифрой). В карточки НЕ превращать.

## 6. Критерии готовности

Полоса читается как три «растворяющихся» панели: взгляд идёт
иконка → цифра → название → описание; колонки разделены мягкой тоновой
ступенькой (сброс градиента), а не линиями; пространство после Hero
структурировано; нет ощущения пустоты, таблиц и UI-карточек ни на одном
брейкпоинте.
