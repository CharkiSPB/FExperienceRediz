# FExperience — Блок «О проекте» (02 / FEXPERIENCE): инструкция AI-агенту (v3)

⚠️ v3 заменяет v2 полностью. Отличия v3: увеличен отступ между текстовой
колонкой и медиа (column-gap 96px); рамка-паспарту выходит за фото
по вертикали (верхняя и нижняя линии вне кромки фото), как в референсе.

## 0. Задача

Точечно дополнить существующий блок «О проекте»: левую текстовую колонку
оставить КАК ЕСТЬ (тексты не меняются), справа добавить фотографию с
двойной рамкой-паспарту и круглую полупрозрачную печать на левой границе
фото.

Референс — только для композиции правой части. Тексты референса НЕ
использовать. Источник текстов — текущая реализация (раздел 1).
Изображение-заглушка в текущем скриншоте — не ориентир; использовать
существующее фото деловой встречи у окна (как в референсе).

## 2. Что именно изменить

- Секция двухколонная: слева текст (eyebrow → statement → подстрока → pills),
  справа медиа-композиция.
- Воздух между колонками — ТОЛЬКО через `column-gap` сетки. Контейнер
  (max-width 1280px, padding 64/32/24px) НЕ менять.
- Медиа-композиция (z-order): двойная рамка-паспарту → фото поверх её
  правой части → печать поверх левой кромки фото и рамки.

## 3. Точные визуальные параметры

### Секция
- Фон `#FFF1E5`; padding-block 96px / 56px; контейнер 1280px,
  padding-inline 64 / 32 / 24px — без изменений.

### Сетка и воздух
```css
.project-grid {
  display: grid;
  grid-template-columns: 55fr 45fr;
  column-gap: 96px;              /* было 64px — увеличить воздух */
  align-items: center;
}
@media (max-width: 1024px) { .project-grid { column-gap: 64px; } }
@media (max-width: 767px)  { .project-grid { column-gap: 0; } }
```
Левый вынос рамки (−28px) визуально сокращает gap; при 96px чистого
воздуха между текстом и линией рамки остаётся ~68px. Не компенсировать
это padding'ами и не сдвигать контейнер.

### Eyebrow — воздух над заголовком (из v2, без изменений)
```css
.project-eyebrow-line { width: 32px; height: 2px; background: var(--orange-600);
                        margin-bottom: 12px; }
.project-eyebrow      { margin-bottom: 32px; }   /* 24px mobile */
```

### Фото
- Существующий кадр деловой встречи у окна (референс), НЕ заглушка.
- `aspect-ratio: 4 / 5; object-fit: cover; border-radius: 12px;`
- Без теней, оверлеев, стекла поверх.

### Рамка-паспарту — ДВОЙНАЯ линия, БОЛЬШЕ фото по вертикали
```css
.project-media { position: relative; }
.project-media__frame {
  position: absolute;
  top: -20px;                 /* верхняя линия ВЫШЕ кромки фото */
  bottom: -20px;              /* нижняя линия НИЖЕ кромки фото */
  left: -28px;                /* левый вынос на фон */
  right: 0;                   /* правый край совпадает с фото */
  border: 1px solid rgba(168,91,63,.50);   /* внешняя линия */
  border-radius: 0;
  pointer-events: none;
  z-index: 0;
}
.project-media__frame::before {
  content: '';
  position: absolute;
  inset: 7px;                 /* внутренняя параллельная линия */
  border: 1px solid rgba(168,91,63,.30);
}
.project-media img { position: relative; z-index: 1; }
```
Видимая геометрия (как в референсе):
- верхняя горизонталь проходит над фото во всю ширину;
- нижняя горизонталь — под фото во всю ширину;
- слева — двойная вертикаль на фоне;
- правая часть рамки скрыта под фото / совпадает с его кромкой.
НЕ делать рамку flush по верху/низу фото. НЕ скруглять углы рамки.
Без надписей на рамке.

### Печать — без изменений из v2
- 120px desktop / 96px mobile; `z-index: 2`; центр на левой кромке фото,
  `top: 30%` — пересекает паспарту, фон и край фото (~50/50).
- Круговая линия 1px `rgba(26,26,26,.55)` (чёрная).
- Текст по кругу (10px, letter-spacing .18em, fill `rgba(26,26,26,.55)`):
  `FORBES FEXPERIENCE · FORBES FEXPERIENCE · FORBES FEXPERIENCE ·`
  (ровно три повтора, круг замкнут).
- Центр: только `F`, Playfair Display 700, `var(--orange-600)`, без `X`.
- Полупрозрачная, без заливки, glow, теней, rotation.

### Анимации
- Медиа-колонка: `.fade-up` + `.delay-2`; печать opacity 0→1, delay .3s.
- Hover отсутствует.

## 7. Критерии готовности

Между текстовым манифестом и медиа — свободный воздух (~68px чистого
зазора до линии рамки). Фото «висит» в двойном терракотовом паспарту,
которое выше и ниже фото и вынесено влево; на левой кромке — чёрная
полупрозрачная печать с оранжевой `F` и тремя повторами по кругу.
Тексты идентичны текущей реализации посимвольно.
