## WHAT'S INCLUDED — FINAL VISUAL IMPLEMENTATION LOCK

### Цель блока

Секция «Что включено» должна выглядеть не как набор UI-карточек и не как стандартный bento-grid.

Это editorial / luxury composition поверх фотографий.

Главный визуальный принцип:

PHOTO → LIQUID GLASS → DARK EDITORIAL TYPOGRAPHY

Стекло является полупрозрачным физическим слоем поверх фотографии, а не непрозрачной карточкой.

НЕ использовать:
- стандартные white cards;
- одинаковые карточки;
- white text + black text внутри одной glass-панели;
- сильный dark overlay;
- обычный card shadow;
- generic bento-grid;
- hover-lift карточек;
- одинаковую композицию для всех 5 элементов.

---

Не воспринимай этот блок как UI-карточки с фотографиями. Представь, что это один журнальный разворот, в котором фотографии являются основным материалом, а стеклянные панели — физическими полупрозрачными листами, лежащими поверх фотографий. У каждой панели должна сохраняться связь с фотографией под ней. Не выравнивай все панели в одинаковую сетку и не придавай им одинаковый визуальный вес.

### 1. Общая композиция

Секция располагается на тёплом светлом фоне:

background:
linear-gradient(
  135deg,
  #FFF8F0 0%,
  #FFE8D6 48%,
  #FFF3E8 100%
);

Композиция асимметричная.

Элемент 01 — главный визуальный блок:
- большая фотография;
- крупный размер;
- glass-panel располагается поверх фотографии;
- panel находится в нижней левой / нижней центральной зоне;
- фотография остаётся хорошо видимой вокруг панели.

Элементы 02 и 03:
- вертикальная последовательность;
- отдельные фотографии;
- небольшие glass overlays;
- не должны выглядеть как одинаковые карточки.

Элементы 04 и 05:
- использовать другой композиционный ритм;
- 04 может быть editorial text-led block без фотографии;
- 05 снова photo-led composition.

Не превращать всю секцию в сетку одинаковых карточек.

---

### 2. LIQUID GLASS

Для блока «Что включено» использовать только светлое тёплое glass.

Базовый glass:

background:
linear-gradient(
  180deg,
  rgba(255, 248, 240, 0.76) 0%,
  rgba(248, 232, 215, 0.64) 55%,
  rgba(244, 221, 198, 0.54) 100%
);

backdrop-filter:
blur(22px) saturate(115%);

-webkit-backdrop-filter:
blur(22px) saturate(115%);

border:
1px solid rgba(255, 255, 255, 0.48);

box-shadow:
inset 0 1px 0 rgba(255, 255, 255, 0.55),
0 14px 40px rgba(65, 40, 22, 0.10);

border-radius:
22px;

ВАЖНО:

Glass должен оставаться прозрачным.

Фотография под стеклом должна быть визуально различима.

НЕ использовать:
background: rgba(255,255,255,0.95);
background: #fff;
background: rgba(0,0,0,...);

Не превращать glass в непрозрачную карточку.

---

### 3. КРИТИЧЕСКОЕ ПРАВИЛО ЧИТАЕМОСТИ

Внутри светлого glass-panel ВСЯ основная типографика должна быть тёмной.

НЕ использовать одновременно:

black heading + white paragraph

или

white heading + black paragraph.

Для стандартного Light Glass:

.heading:
#171411;

.body:
rgba(23, 20, 17, 0.70);

.number:
#F29A72;

Таким образом весь текст внутри одной панели имеет единую светлую editorial-типографическую систему.

Белый текст разрешён ТОЛЬКО внутри специально созданного Dark Glass.

В этом блоке Dark Glass НЕ использовать.

---

### 4. Локальная зона повышенной читаемости

Если на конкретной фотографии под glass-panel остаётся слишком контрастный участок, НЕ затемнять всю фотографию.

Усилить только сам glass-panel.

Допускается дополнительный локальный слой:

background:
linear-gradient(
  180deg,
  rgba(255, 248, 240, 0.78) 0%,
  rgba(255, 248, 240, 0.68) 100%
);

Это должно повышать читаемость текста, но сохранять видимость фотографии.

НЕ использовать чёрный gradient под текстом.

---

### 6. НЕ УМЕНЬШАТЬ ТЕКСТ РАДИ ФОТОГРАФИИ

Если текст не помещается:

1. сначала увеличить glass-panel;
2. затем изменить его положение;
3. затем немного увеличить прозрачность/плотность glass;
4. только после этого корректировать размер текста.

НЕ делать body-text 11–12px ради сохранения маленькой карточки.

Минимальный desktop body:
16px.

Минимальный mobile body:
15px.

Читаемость важнее компактности.

---

### 7. ПАНЕЛЬ 01

01 — главный feature.

Фото занимает большую площадь.

Glass-panel не должен закрывать всё изображение.

Пример структуры:

[ LARGE PHOTO ]

       ┌─────────────────────────────┐
       │ 01                          │
       │                             │
       │ Уникальный нетворкинг Forbes│
       │                             │
       │ Деловое общение с...        │
       │                             │
       └─────────────────────────────┘

Panel должен занимать примерно 55–72% ширины фотографии,
а не 100%.

Panel располагается ближе к нижней части изображения.

---

### 8. ПАНЕЛИ 02–03

Glass-panel должен быть компактнее, но сохранять ту же систему:

01 / 02 / 03
→ peach number
→ dark Playfair heading
→ dark HelveticaNeueCyr body

Не использовать white text.

Не делать панели одинаковыми по высоте, если контент этого не требует.

---

### 9. ЭЛЕМЕНТ 04

04 — намеренно text-led.

Не нужно искусственно помещать фотографию только ради сохранения сетки.

Можно оставить:

04

Контакты с госструктурами

Прямой диалог с представителями торговых палат,
регуляторов и госаппарата. Без бюрократии,
без посредников.

На тёплом gradient background.

Это создаёт паузу между photo-led композициями.

---

### 10. ЭЛЕМЕНТ 05

05 снова photo-led.

Использовать фотографию + light glass.

Не использовать dark glass только потому, что фотография тёмная.

Сначала обеспечить читаемость через светлую translucent glass surface.

---

### 11. HOVER

НЕ использовать:

transform: translateY(-6px);

для всей панели.

Glass-panel должен ощущаться как физический слой.

Допустимо:

- очень лёгкое изменение opacity;
- изменение border highlight;
- небольшое усиление backdrop-filter;
- очень медленный zoom фотографии на 1–2%.

Например:

.photo img {
  transition: transform 700ms cubic-bezier(.2,.7,.2,1);
}

.feature:hover img {
  transform: scale(1.02);
}

Glass-panel при этом не должен «прыгать».

---

### 12. ФИНАЛЬНЫЙ КРИТЕРИЙ

После реализации пользователь должен видеть:

ФОТОГРАФИЯ
↓
прозрачный тёплый glass
↓
Playfair Display
↓
HelveticaNeueCyr

а не:

CARD
CARD
CARD
CARD
CARD

Если результат выглядит как обычная коллекция одинаковых UI-карточек — реализация считается НЕУДАЧНОЙ.

Если glass выглядит как непрозрачный белый прямоугольник — реализация считается НЕУДАЧНОЙ.

Если для читаемости используется чёрный overlay поверх всей фотографии — реализация считается НЕУДАЧНОЙ.

Если текст приходится уменьшать ниже 15–16px ради сохранения композиции — реализация считается НЕУДАЧНОЙ.
