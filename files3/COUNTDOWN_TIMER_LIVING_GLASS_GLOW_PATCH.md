# COUNTDOWN TIMER — LIVING GLASS GLOW PATCH

## Назначение

Точечный визуальный PATCH только для стеклянного контейнера Countdown Timer на главной странице.

Текущую композицию таймера НЕ переделывать.

Цель: сделать светлое стекло визуально «живым» за счёт очень слабого тёплого отражённого свечения.

---

## 1. Сохранить без изменений

- единый стеклянный контейнер;
- тёплый светлый фон;
- оранжевые цифры;
- Playfair Display для цифр;
- HelveticaNeueCyr для служебного текста;
- четыре значения в одной композиции;
- тонкие разделители;
- подпись ближайшей экспедиции;
- текущие размеры и расположение;
- существующую countdown-логику;
- существующий источник даты.

В рамках этого PATCH ничего из перечисленного не менять.

---

## 2. Визуальная цель

Стекло должно перестать выглядеть как обычная белая полупрозрачная карточка.

Нужное ощущение:

> тонкое матовое архитектурное стекло, на которое падает мягкий тёплый отражённый свет.

Эффект должен быть очень слабым, тёплым, дорогим, спокойным и почти незаметным.

Пользователь должен сначала видеть таймер, а только потом замечать, что поверхность стекла слегка меняет свет и температуру.

---

## 3. Главное правило — не делать сильный glow

ЗАПРЕЩЕНО:

- neon glow;
- яркая оранжевая подсветка;
- сильное внешнее свечение;
- оранжевая рамка;
- gradient border;
- яркий orange halo;
- сильный blur вокруг всей карточки;
- светящаяся кнопка;
- gaming/neon aesthetic;
- dashboard glassmorphism.

Если пользователь сразу замечает свечение как самостоятельный декоративный эффект — оно слишком сильное.

---

## 4. Базовая поверхность стекла

Сохранить светлую поверхность. Не затемнять контейнер.

```css
.home-countdown {
  position: relative;
  overflow: hidden;

  border: 1px solid rgba(255, 255, 255, 0.68);
  border-radius: 28px;

  background:
    linear-gradient(
      135deg,
      rgba(255, 255, 255, 0.58),
      rgba(255, 255, 255, 0.30)
    );

  backdrop-filter: blur(22px) saturate(135%);
  -webkit-backdrop-filter: blur(22px) saturate(135%);

  box-shadow:
    0 18px 50px rgba(120, 66, 30, 0.07),
    inset 0 1px 0 rgba(255, 255, 255, 0.85);
}
```

Если существующие значения уже близки к этим — не заменять их без необходимости.

---

## 5. Первое тёплое отражение

Добавить очень мягкое внутреннее свечение сверху справа:

```css
.home-countdown::before {
  content: "";
  position: absolute;

  width: 320px;
  height: 220px;

  top: -150px;
  right: 80px;

  background: rgba(255, 107, 44, 0.055);

  filter: blur(70px);
  border-radius: 50%;

  pointer-events: none;
  z-index: 0;
}
```

`0.055` — ориентир, а не повод усиливать эффект.

Свечение не должно выглядеть как отдельное оранжевое пятно.

---

## 6. Второе отражение

Добавить ещё более слабое тёплое отражение снизу слева:

```css
.home-countdown::after {
  content: "";
  position: absolute;

  width: 260px;
  height: 160px;

  left: -100px;
  bottom: -110px;

  background: rgba(255, 145, 90, 0.035);

  filter: blur(65px);
  border-radius: 50%;

  pointer-events: none;
  z-index: 0;
}
```

Второе свечение должно быть слабее первого. Оно нужно только для того, чтобы поверхность не выглядела полностью плоской.

---

## 7. Контент всегда выше свечения

Декоративные псевдоэлементы не должны влиять на читаемость:

```css
.home-countdown__eyebrow,
.home-countdown__values,
.home-countdown__caption {
  position: relative;
  z-index: 1;
}
```

Свечение не должно размывать цифры, менять их цвет, снижать контраст или создавать яркое пятно непосредственно под текстом.

---

## 8. Верхний highlight

Свет должен слегка отражаться на верхней внутренней границе стекла:

```css
box-shadow:
  0 18px 50px rgba(120, 66, 30, 0.07),
  inset 0 1px 0 rgba(255, 255, 255, 0.85);
```

Это должно выглядеть как отражение света на стеклянной поверхности, а не как яркая белая рамка.

---

## 9. Граница

Граница остаётся нейтральной и почти невидимой:

```css
border: 1px solid rgba(255, 255, 255, 0.68);
```

Не использовать оранжевую border.

Оранжевый должен появляться в световом отражении и в фирменных цифрах, а не превращать весь контейнер в оранжевую карточку.

---

## 10. Не анимировать свечение

В этом PATCH не добавлять:

- pulsing glow;
- moving glow;
- breathing animation;
- animated gradient;
- бегущий блик;
- постоянное движение светового пятна.

Стекло должно быть «живым» визуально, а не буквально двигаться.

---

## 11. Правильная интенсивность

Если убрать псевдоэлементы и разница между версиями почти незаметна — это нормально.

Если свечение заметно сразу как отдельный декоративный элемент — уменьшить opacity минимум в 2 раза.

При сомнении между «чуть заметнее» и «чуть слабее» всегда выбирать **чуть слабее**.

---

## 12. Визуальная проверка

Сравнить вариант без свечения и вариант со свечением.

Вариант со свечением должен ощущаться:

- теплее;
- глубже;
- немного более материальным;

но не:

- ярче;
- более оранжевым;
- более декоративным;
- более «неоновым».

---

## 13. Не менять композицию Countdown

Этот PATCH НЕ разрешает менять:

- размер контейнера;
- высоту контейнера;
- расположение;
- размеры цифр;
- шрифты;
- тексты;
- интервалы;
- количество колонок;
- разделители;
- данные экспедиции;
- countdown-логику;
- Hero;
- HeroSlider;
- соседние блоки.

Работа только со стеклянной поверхностью и очень слабым тёплым светом.

---

## 14. Acceptance checklist

- [ ] Стекло осталось светлым.
- [ ] Контейнер не стал тёмным.
- [ ] Нет оранжевой рамки.
- [ ] Нет neon glow.
- [ ] Нет сильного внешнего halo.
- [ ] Есть очень слабое тёплое отражение.
- [ ] Верхнее отражение выглядит как свет на стекле.
- [ ] Второе отражение почти незаметно.
- [ ] Текст и цифры полностью читаемы.
- [ ] Цифры не изменили цвет.
- [ ] Нет анимации свечения.
- [ ] Нет moving gradient.
- [ ] Countdown-логика не изменена.
- [ ] Hero и другие блоки не изменены.
- [ ] Таймер по-прежнему выглядит как единый премиальный объект, а не набор карточек.

---

## 15. Ключевой критерий

> **Стекло должно выглядеть живым, но свечение не должно выглядеть как эффект.**

Нужна материальность, а не декоративность.
